# NOVA X1 | Meet What's Next

A responsive HTML, CSS and JavaScript technology product landing page created for the Web Development subject activity.

## Run locally
1. Download or clone this project folder.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Internet is needed for Google Fonts and the remote Unsplash product image.

## Deploy with GitHub Pages
Open **Settings → Pages → Deploy from a branch → main → /(root)** and save.
